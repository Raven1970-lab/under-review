# Under Review

A narrative browser game set at a public-service desk. Check records, inspect photographs, and process applications across a working day.

Play: https://raven1970-lab.github.io/under-review/

Serve this directory with a static HTTP server, then open index.html. No build step is required.

The interface and dialogue support English and Simplified Chinese. Switch languages without restarting the current encounter. Character dossiers unlock after encounters and include links to the documentary sources used in the work.
